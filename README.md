# About
This repo contains variations of different colors based on IceWM "Cromo" theme (colloquially known as Crux), including dark variants too.

This repo also includes color variants for the original GTK "Crux" theme, which was only available in purple. Dark variants are also included.

I omitted the use of ledclocks in IceWM for the dark variants to save myself some work, too lazy.
